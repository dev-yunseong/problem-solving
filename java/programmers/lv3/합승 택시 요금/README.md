# 합승 택시 요금

같은 곳에서 출발해서 다른 곳으로 갈 때 두사람이 모두 귀가하는 데 소요되는 예상 최저 택시 요금을 구하는 문제

S에서 출발 하여서 각각 A, B로 간다.

택시 합승을 적절히 이용
S -> O
O -> A
O -> B
의 합이 최소가 되도록

플로이드 워샬을 통해서 모든 곳에서 모든 곳으로의 거리를 구한 후 최소 값을 찾음

200^3 = 8000000 이기에 시간도 가능할 것


## 배운 점
- 플로이드 워셜 알고리즘
    - 아래와 같이 중간 지점이 맨 밖의 반복문이어야한다.
```java
for (int k = 0; k < n; k++) {
    for (int j = 0; j < n; j++) {
        for (int i = 0; i < n; i++) {
            fareMatrix[i][j] = Math.min(fareMatrix[i][j], fareMatrix[i][k] + fareMatrix[k][j]);
        }
    }
}
```
