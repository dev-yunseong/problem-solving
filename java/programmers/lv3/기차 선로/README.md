# 기차 선로

## 문제
- 기차 선로를 배치하는 경우의 수를 구하라
- 조건:
    - (1, 1)에서 (n, m)까지 이어져야한다.
    - 배치된 기차 선로들은 모두 연결 되어있어야한다.

## 문제 푼 방법
- DFS를 사용
  - flow
    1. 현재 위치가 완료된 위치인지 확인한다. 
      1. 도착 위치라면 선로들 중 사용되지 않는 것이 있는지를 순회하며 확인한다. 
      2. 사용되지 않는 것이 없을시 경우의 수로 인정한다.
    2. 현재 타일의 종류를 확인한다.
      - 현재 타일이 비어있다면 이전 방향과 연결되는 tile을 선택하여 다음 칸으로 이동하여 반복한다.
      - 현재 타일이 정해져있다면 정해진 다음 칸으로 이동하여 반복한다.
