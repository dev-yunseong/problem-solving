# 카드 짝 맞추기

## 문제
4x4 격자 형태
각각 카카오프렌즈 캐릭터 2개 짝짓기를 해야함

커서를 사용해서 선택
- 방향키로 1칸 움직일 수 있음
- ctrl을 누른 상태로 방향키로 그 방향에 가장 가까운 카드로 이동 (그 방향에 카드가 없다면 맨 끝 칸으로 이동)
- enter를 눌러서 카드 뒤집기

## 문제 풀 방법
dfs로 어떤 카드부터 제거 하는게 빠른지 찾기
bfs로 이동하는 최소 횟수를 찾기 (bfs로 다 하면 board 상태가 복잡해져서 구현이 복잡해지고 메모리 사용이 많아짐)

## 배운점
col, row 인자 위치를 헷갈렸어서 메서드 하나에서만 둘을 반전해서 유지했었음
하지만 그 결정 때문에 코드를 일관적으로 읽기 힘들어져서 버그를 찾을 수 없었음
